# Aegis — Phase 1

This repository contains the Phase 1 foundation for Aegis: an AI-native application security intelligence platform.

Phase 1 focuses on scaffolding a production-grade monorepo with frontend, backend, infra, and integration foundations.

Goals achieved in Phase 1:
- Monorepo scaffold (frontend, backend, docker, docs)
- FastAPI backend skeleton with modular layout
- Next.js frontend skeleton (App Router) with dark-first layout
- Docker Compose for local dev (Postgres, Redis, Neo4j, Qdrant)

See `docs/architecture.md` for high-level design.
